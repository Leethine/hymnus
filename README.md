# hymnus
HYMNUS (HYpertext Manager for MUsicical Notation Scripts) is a web-based tool for music score library management. 

Features:
 - a minimalist DB
 - web app based on Flask
 - create, modify or delete music score metadata
 - upload, modify or delete music score
 - dummy search engine

# Running
Please follow the [INSTALLATION](/flask_app/INSTALL.md) guide for the installation and deployment.

# Scripts
The legacy scripts are used to manage the library from back-end side, it is deprecated now. It will slowly be removed in the future releases.
